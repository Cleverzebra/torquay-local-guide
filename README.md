# Torquay & the Surf Coast · A Field Guide

A personalised activity guide for one Torquay (VIC) family: Audrey, Ben, Macie, and the dog.

**Live site:** https://cleverzebra.github.io/torquay-local-guide/

One interactive page, 10 tabs, filter bar (free / under $25 / 15 min from Torquay / kids / dog),
organised by drive-time rings out from Torquay. Covers events and festivals with verified dates
Aug 2026 – Jul 2027, the live-music circuit, pilates/spa/self-care, craft and jewellery-making,
markets, hidden-gem food in the surrounding towns, nature walks, wildlife missions, and the
Surf Coast dog rules.

The page is date-aware: each time it opens it highlights the current month (Melbourne time)
on the year calendar and swaps the seasonal line in the hero.

Compiled late July 2026 from organiser, shire, parks and venue sources; each entry flags
verified vs pattern-based dates. First names only by design.

Built as a companion to the Natick guide (natick-local-guide) using the same design system.
